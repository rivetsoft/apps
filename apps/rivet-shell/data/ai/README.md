# AI provider logos

The AI Usage item's logos, from LobeHub's icon set (`@lobehub/icons-static-svg` 1.80.0, MIT
licence, https://github.com/lobehub/lobe-icons): `claude-color`, `openai` (shown for Codex),
`grok`, `openrouter` and `deepseek-color`. The marks themselves belong to their companies and are
used only to show which service a number is about. The ones with `fill="currentColor"` are drawn
in the panel's text colour.

`hermes.svg` (Hermes Agent, by Nous Research) is drawn for Rivet: a winged staff, the sign of
Hermes, in the panel's text colour. Nous Research's own artwork is an illustration that doesn't
read at 16 pixels.
