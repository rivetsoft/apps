# Shared plugins

`registry.json` is the list of Rivet Shell plugins other people have shared. Rivet Shell reads it
(Settings, Plugins, Get Plugins, and `rivet-shell plugin available`) and so does the
website.

To add yours, open a pull request that changes `registry.json`. A plugin is listed once; its
author publishes updates themselves, in the release file the listing points to. What a listing
and a release file need is in
[PLUGINS.md](../apps/rivet-shell/PLUGINS.md#sharing-a-plugin).
